Módulo 01 • Conceitos Visuais

IA Discriminativa vs.
IA Generativa

A fronteira matemática entre classificar dados existentes e sintetizar criações inéditas.

O Paradigma Matemático: P(Y|X) vs. P(X)

IA Discriminativa
Probabilidade Condicional P(Y | X)
Entrada (X)
Foto, E-mail ou Tabela CSV
Fronteira de Decisão
KNN, Random Forest, SVM
Rótulo / Classe (Y)
" É Spam (98%)" ou "Vinho Classe 0"
IA Generativa
Distribuição Conjunta P(X) / P(X | Y)
Prompt / Contexto (Y)
Instrução em Linguagem Natural
Modelo de Fundação
Amostragem no Espaço Latente
Instância Inédita (X*)
Código Python, Texto, Imagem, Áudio

Quando usar IA Discriminativa?

Quando a resposta é um número, categoria ou alerta extraído de dados históricos: Previsão de Churn (abandono), detecção de fraude no cartão, aprovação de crédito ou contagem de peças.

Quando usar IA Generativa?

Quando o sistema precisa produzir um artefato complexo: Redigir uma mensagem personalizada para o cliente que abandonou o carrinho, explicar um bug, resumir contratos ou sintetizar imagens.

Por que "Modelo de Fundação"? Ao contrário do Machine Learning clássico (onde treinamos um modelo do zero para cada tarefa), um Foundation Model passa por um pré-treinamento massivo não supervisionado e serve como alicerce único para centenas de aplicações via Prompting, RAG ou Fine-Tuning.

Controle Matemático da Geração: Temperatura

Os LLMs preveem uma distribuição de probabilidades para o próximo token. O hiperparâmetro temperature achata ou afunila essa curva:

Temp: 0.0 a 0.2

Determinístico / Lógico

Escolhe sempre o token de maior probabilidade matemática (Greedy Decoding).

Uso Ideal: Geração de JSON para APIs, SQL, refatoração de código e cálculos.

Temp: 0.4 a 0.7

Equilibrado / Natural

Mantém a coerência técnica permitindo variações naturais de vocabulário.

Uso Ideal: Assistentes virtuais, tutoria socrática, documentação e resumos.

Temp: 0.8 a 1.2+

Criativo / Exploratório

Permite que tokens menos prováveis sejam sorteados. Acima de 1.2 aumenta o risco de alucinação.

Uso Ideal: Brainstorming, criação de roteiros de jogos e campanhas de marketing.

Regra de Produção: Quando quem vai ler a saída da IA é um script Python (via json.loads()), utilize sempre temperature=0.1 e defina o Formato estrito no System Prompt.

Módulo 02 • Engenharia de Prompt Socrática

O Detetive de Bugs &
O Oráculo de Python

Transformando a IA de uma "calculadora que entrega respostas prontas" em um Mentor Investigativo.

Depuração com Pato de Borracha & Socratic Prompting

Rubber Duck Debugging

Na engenharia de software clássica, o programador explica seu código linha por linha para um patinho de borracha na mesa. Ao verbalizar a lógica, o próprio cérebro identifica onde está a falha.

A Armadilha do Iniciante com IA: Colar o código com erro e dizer "Conserta pra mim". O código roda, mas o desenvolvedor não aprende a diagnosticar a causa-raiz.

Socratic Prompting (Fórmula C.I.C.P.)

Usamos restrições negativas (Guardrails) para obrigar o LLM a agir como um Tutor Socrático que guia o aluno por meio de perguntas:

  • C — Contexto: "Sou estudante de Python depurando um sistema escolar."
  • I — Instrução + Restrição: "Analise o código, mas NUNCA entregue o código corrigido."
  • C — Cenário: "Aponte os erros de sintaxe, tipo e lógica através de pistas e perguntas."
  • P — Personalização: "Adote a persona de um Oráculo/Detetive implacável."

# BLOCO 1: Gerando e inspecionando a base de E-Commerce import pandas as pd import numpy as np np.random.seed(42) n = 200 tempo_site = np.random.uniform(1, 30, n).round(1) paginas = np.random.randint(1, 20, n) carrinho = np.random.uniform(20, 1500, n).round(2) abandonos = np.random.randint(0, 6, n) # Regra de negócio histórica (0 = Abandonou, 1 = Comprou) score = (tempo_site * 0.4) + (paginas * 0.8) - (abandonos * 3.5) + (carrinho * 0.005) comprou = (score > 10).astype(int) df = pd.DataFrame({ 'tempo_site_min': tempo_site, 'paginas_visitadas': paginas, 'valor_carrinho': carrinho, 'abandonos_anteriores': abandonos, 'comprou': comprou }) df.to_csv('ecommerce_clientes.csv', index=False) print(df.head()) print("\nDistribuição da classe alvo:\n", df['comprou'].value_counts())
