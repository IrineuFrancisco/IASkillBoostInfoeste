Intents (Intenções)

O verbo / objetivo do usuário (ex: pedido-coxinha, pedido.pizza). Usa Training Phrases para generalizar frases nunca vistas por similaridade vetorial.

Entities (Entidades)

Os substantivos / variáveis extraídos da frase: Customizadas (@produto, @Sabor) ou de Sistema (@sys.number, @sys.address).

Slot Filling

Quando marcamos um parâmetro como Required, o bot faz perguntas automáticas (Prompts) caso o cliente esqueça algum dado.

Contextos

A memória de curto prazo da conversa (Lifespan de interações), permitindo confirmar um pedido sem perder os dados anteriores.

Lab 5.1: Configurando o Agente no Google Dialogflow ES

Parte A: Cantina SENAI (Para o Webhook)

  • 1. Criar Agente: Acesse dialogflow.cloud.google.com $\to$ Create Agent $\to$ Nome: SENAIBOT | Idioma: Portuguese (pt-br).
  • 2. Criar Entity (@produto): Vá em Entities $\to$ Create Entity, nomeie como produto e adicione os valores coxinha de frango e coxinha de costela (com sinônimos).
  • 3. Criar Intent (pedido-coxinha): Adicione frases de treino como "Quero 2 coxinhas de frango" e "Vou querer 5 de costela".
  • 4. Action and Parameters: Marque qtde (@sys.number) e produto (@produto) como REQUIRED.
  • 5. Ativar Webhook: No rodapé da Intent, em Fulfillment, marque Enable webhook call for this intent e clique em Save!
Required Parameter Name Entity Value Prompt (Se o usuário esquecer)
✅ qtde @sys.number $qtde "Quantas unidades você deseja?"
✅ produto @produto $produto "Qual sabor? (Frango ou Costela)"
✅ (Opcional) endereco @sys.address $endereco "Qual o local de entrega?"

Publicação Moderna (Dialogflow Messenger):
No menu lateral esquerdo, clique em Integrations $\to$ Dialogflow Messenger $\to$ Enable. Ele gera a tag HTML <df-messenger> com o seu agent-id exclusivo para embutirmos no servidor PythonAnywhere!

Lab 5.2: Código flask_app.py — Bloco 1 (Página Web + Chat)

Abra /home/SEU_USUARIO/mysite/flask_app.py no editor do PythonAnywhere. O Bloco 1 cria a rota principal GET / que exibe o site da Cantina com o balão do <df-messenger>:

from flask import Flask, url_for, make_response, request, jsonify app = Flask(__name__) pedidos = [] # Lista global em memória para armazenar os pedidos @app.route('/', methods=["GET"]) def website(): # IMPORTANTE: Substitua o agent-id pelo ID do seu agente Dialogflow! return """ <html> <head> <meta name="viewport" content="width=device-width, initial-scale=1"> </head> <body> <h2>Cantina Inteligente SENAI-SP</h2> <h4>Atendimento Automatizado via Google Dialogflow + Flask</h4> <script src="https://www.gstatic.com/dialogflow-console/fast/messenger/bootstrap.js?v=1"></script> <df-messenger intent="WELCOME" chat-title="SENAIBOT" agent-id="COLE-AQUI-O-SEU-AGENT-ID" language-code="pt-br" chat-icon='%s'> </df-messenger> </body> </html> """ % url_for('static', filename='images/robot.png')

Como funciona a Rota /?

1. Quando o cliente acessa https://seuusuario.pythonanywhere.com/ pelo navegador, o Flask executa website().

2. A tag <df-messenger> carrega o widget flutuante oficial do Google Cloud conectado ao seu agent-id.

3. O url_for('static', ...) injeta dinamicamente o ícone robot.png no botão do chat!

Lab 5.2: Código flask_app.py — Bloco 2 (Rota /webhook)

@app.route('/webhook', methods=["POST"]) def processarIntent(): payload = request.get_json() intent = payload.get('queryResult', {}).get('intent', {}) if intent.get('displayName') == 'pedido-coxinha': source = payload.get("originalDetectIntentRequest", {}).get("source") resposta = {"fulfillmentMessages": []} parametro = payload.get('queryResult', {}).get('parameters', {}) qtde = parametro.get("qtde") prod = parametro.get("produto") pedidos.append({"produto": prod, "qtde": qtde}) msg = f"Ok, seu pedido de {qtde:.0f} {prod} foi registrado no servidor!" return enviarCards(msg, source, resposta) return make_response(jsonify({"fulfillmentText": "Intent não reconhecida pelo Webhook."})) def enviarCards(msg, source, resposta): if source == "DIALOGFLOW_CONSOLE" or source == "telegram": resposta['fulfillmentMessages'].append({ "card": {"title": "Pedido Confirmado", "subtitle": msg} }) else: resposta["fulfillmentMessages"].append({ "payload": {"richContent": [[{"type": "info", "title": "Confirmação de Pedido", "subtitle": msg}]]} }) return make_response(jsonify(resposta))

Lab 5.2: Passo 4 — Ativando o Webhook e Depurando Erros

Vinculando as Pontas (Fulfillment)

  • 1. Reload no PythonAnywhere: Salve o flask_app.py, vá na aba Web e clique no botão verde Reload.
  • 2. Copiar URL do Webhook: Copie o endereço público da sua aplicação acrescentando /webhook ao final:
    https://seuusuario.pythonanywhere.com/webhook
  • 3. Colar no Dialogflow: No menu Fulfillment do Dialogflow, ative a chave Webhook (Enabled), cole a URL e clique em Save.
  • 4. Teste Duplo: Teste no simulador lateral (Try it now) e diretamente na página web https://seuusuario.pythonanywhere.com/!

Troubleshooting & Expansão IoT (Wokwi)

  • Erro 500 ou "Webhook call failed": Na aba Web do PythonAnywhere, role até Log files $\to$ error.log e leia as últimas linhas (verifique indentação ou nome da variável no WSGI).
  • Nome Exato da Intent: O nome no Dialogflow (pedido-coxinha) deve ser idêntico à string no if intent.get('displayName') do Python!
  • Expansão IoT (Bônus Wokwi): Adicionando uma rota GET /get_blinks no mesmo Flask, um microcontrolador Raspberry Pi Pico W / ESP32 no simulador Wokwi consegue ler os comandos do seu Chatbot e acionar LEDs/relés físicos!
