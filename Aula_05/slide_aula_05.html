Intents (Intenções)

O verbo / objetivo do usuário (ex: pedido.pizza, agendamento.servico). Usa Training Phrases para generalizar frases reais por similaridade vetorial.

Entities (Entidades)

Os substantivos / variáveis: Customizadas (@Sabor, @Tamanho, @FormaPagamento) ou de Sistema (@sys.address, @sys.date-time).

Slot Filling

Se o cliente diz apenas "Quero pizza", parâmetros marcados como Required disparam perguntas automáticas (Prompts) até completar o pedido.

Contextos

A memória de curto prazo (Lifespan de interações), permitindo que respostas como "Sim" confirmem o pedido-em-andamento.

Lab 5.1: Configurando o Agente do Projeto DialogFlow.md

Pizzaria IA-Bot (Delivery Inteligente)

  • 1. Criar Agente: Acesse dialogflow.cloud.google.com $\to$ Create Agent $\to$ Nome: Pizzaria_IA_Bot | Idioma: Portuguese (pt-br).
  • 2. Entidades do Negócio: Cadastre @Sabor (Calabresa, Mussarela, Margherita), @Tamanho (Broto, Média, Grande) e @FormaPagamento (PIX, Cartão, Dinheiro).
  • 3. Criar Intent (pedido.pizza): Adicione frases como "Tô com fome, me vê uma grande de calabresa" e "Quero mussarela média no PIX".

  • 5. Ativar Webhook: Em Fulfillment, marque Enable webhook call for this intent e clique em Save!

Como funciona a Rota /?

1. Ao acessar https://seuusuario.pythonanywhere.com/, o Flask responde com o portal web.

2. A tag <df-messenger> renderiza o balão flutuante oficial do Google Cloud conectado ao seu agent-id.

3. O url_for('static', ...) insere o ícone robot.png diretamente no botão de abertura!

Lab 5.2: Código flask_app.py — Bloco 2 (Rota /webhook)

@app.route('/webhook', methods=["POST"]) def processarIntent(): payload = request.get_json(silent=True, force=True) or {} intent_name = payload.get('queryResult', {}).get('intent', {}).get('displayName', '') source = payload.get("originalDetectIntentRequest", {}).get("source") resposta = {"fulfillmentMessages": []} if intent_name == 'pedido.pizza': params = payload.get('queryResult', {}).get('parameters', {}) sabor = params.get("sabor", "Calabresa") tamanho = params.get("tamanho", "Grande") pag = params.get("pagamento", "PIX") end = params.get("endereco", "Retirada") pedidos.append({"sabor": sabor, "tamanho": tamanho, "pagamento": pag, "endereco": end}) msg = f"Pizza de {sabor} ({tamanho}) anotada! Entrega em {end} ({pag})." return enviarCards("🍕 Pedido Registrado!", msg, source, resposta) return make_response(jsonify({"fulfillmentText": "Intent não reconhecida."})) def enviarCards(titulo, msg, source, resposta): if source == "DIALOGFLOW_CONSOLE": resposta['fulfillmentMessages'].append({"card": {"title": titulo, "subtitle": msg}}) else: resposta["fulfillmentMessages"].append({ "payload": {"richContent": [[{"type": "info", "title": titulo, "subtitle": msg}]]} }) return make_response(jsonify(resposta))

Lab 5.2: Passo 4 — Ativando o Webhook e Depurando Erros

Vinculando as Pontas (Fulfillment)

  • 1. Reload no PythonAnywhere: Salve o flask_app.py, vá na aba Web e clique no botão verde Reload.
  • 2. Copiar URL do Webhook: Copie o endereço público da sua aplicação acrescentando /webhook ao final:
    https://seuusuario.pythonanywhere.com/webhook
  • 3. Colar no Dialogflow: No menu Fulfillment do Dialogflow, ative a chave Webhook (Enabled), cole a URL e clique em Save.
  • 4. Teste Duplo: Teste no simulador lateral (Try it now) e diretamente na página web https://seuusuario.pythonanywhere.com/!

Troubleshooting & Nome de Intents

  • Erro 500 ou "Webhook call failed": Na aba Web do PythonAnywhere, role até Log files $\to$ error.log e leia as últimas linhas (verifique indentação ou módulos importados).
  • Nome Exato da Intent: O nome no Dialogflow (pedido.pizza) deve ser idêntico à string no if intent_name == 'pedido.pizza' do Python!
  • Ativação por Intent: Lembre-se de rolar até o rodapé da Intent no Dialogflow e marcar Enable webhook call for this intent!
